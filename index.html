Вход через VK и Яндекс

Код в приложении уже готов. Тебе нужно завести два приложения в кабинетах и прописать публичные id. Секреты в телефон не кладём.

Что должно получиться

В `.env` три строки. Redirect везде один и тот же:

pvzpro://oauth

VK ID

  1. Открой кабинет VK ID (нужен аккаунт VK).
  2. Подключи VK ID и создай приложение. Платформа — сайт / без SDK или Android, как предложит мастер.
  3. В настройках приложения найди идентификатор приложения (это client_id, число вроде 7915193).
  4. В список доверенных redirect URL добавь ровно:
pvzpro://oauth

Если кабинет принимает только https — добавь ещё и https://oauth.vk.com/blank.html не нужно: нам нужен именно pvzpro://oauth. Если поле ругается на схему, выбери тип «мобильное / custom URL».

Открыть кабинет VK ID Как создать приложение

Яндекс ID

  1. Войди в Яндекс OAuth тем аккаунтом, с которого ведёшь разработку.
  2. Создай приложение для авторизации пользователей.
  3. Платформы: отметь Android и при необходимости «Веб-сервисы».
  4. Redirect URI — снова ровно:
pvzpro://oauth
  1. Скопируй ClientID (длинная строка). Client secret в приложение не копируй.
  2. Доступ: логин и адрес почты (если мастер спросит).

Пропиши id в проекте

На компьютере, в папке проекта, файл .env (если нет — скопируй .env.example).

EXPO_PUBLIC_VK_CLIENT_ID=сюда_число_из_VK EXPO_PUBLIC_YANDEX_CLIENT_ID=сюда_ClientID_Яндекса EXPO_PUBLIC_OAUTH_REDIRECT_URI=pvzpro://oauth

Публичные id, не пароли. В git этот файл не коммитим.

После сохранения напиши в чат агента: «id прописал, обнови preview». Ключи сами вшиваются в JS при OTA. Пока Metro/OTA не пересобрали — кнопки не увидят новые id.

Проверь на телефоне

  1. Обнови приложение (OTA preview).
  2. На экране «Войти» нажми синий VK или красный Я.
  3. Должен открыться браузер сервиса, не список мок-профилей.
  4. Если id пустые — будет ошибка «Не задан client id». Это нормально, пока шаг 3 не сделан.

Почта и телефон работают как раньше, их трогать не нужно.

Если не пускает

  • redirect_uri не совпадает — в кабинете и в .env буква в букву pvzpro://oauth.
  • Сборка старая — после правки .env нужен новый OTA, не просто перезапуск экрана.
  • Сборка pzbro — схема другая: pzbrodev://oauth. Тогда и в кабинетах, и в .env укажи её.
