# ПВЗ Про — вход через VK и Яндекс

Код в приложении уже готов. Нужно завести два приложения в кабинетах и прописать публичные id. **Секреты в телефон не кладём.**

Redirect везде один:

```
pvzpro://oauth
```

---

## 1. VK ID

1. Открой [кабинет VK ID](https://id.vk.ru/about/business) (нужен аккаунт VK).
2. Подключи VK ID и создай приложение. Платформа — **сайт / без SDK** или Android.
3. Скопируй **идентификатор приложения** (`client_id`, число вроде `7915193`).
4. В доверенные redirect URL добавь ровно:

```
pvzpro://oauth
```

Если поле ругается на схему `pvzpro://`, выбери тип «мобильное / custom URL».

Как создать: [документация VK](https://id.vk.ru/about/business/go/docs/ru/vkid/latest/vk-id/connection/create-application)

---

## 2. Яндекс ID

1. Войди в [Яндекс OAuth](https://oauth.yandex.ru/client/new) аккаунтом разработки.
2. Создай приложение **для авторизации пользователей**.
3. Платформы: **Android** и при необходимости «Веб-сервисы».
4. Redirect URI — снова:

```
pvzpro://oauth
```

5. Скопируй **ClientID**. Client secret **не копируй**.
6. Доступ: логин и почта, если мастер спросит.

Документация: [регистрация приложения](https://yandex.ru/dev/id/doc/ru/register-client)

---

## 3. Пропиши id в проекте

На компьютере, в папке проекта, файл `.env` (если нет — скопируй `.env.example`):

```
EXPO_PUBLIC_VK_CLIENT_ID=сюда_число_из_VK
EXPO_PUBLIC_YANDEX_CLIENT_ID=сюда_ClientID_Яндекса
EXPO_PUBLIC_OAUTH_REDIRECT_URI=pvzpro://oauth
```

Публичные id, не пароли. В git не коммитим.

После сохранения напиши в чат: **id прописал, обнови preview**.  
Пока не уйдёт новый OTA, кнопки новые id не увидят.

---

## 4. Проверь на телефоне

1. Обнови приложение (OTA preview).
2. На экране «Войти» нажми синий **VK** или красный **Я**.
3. Должен открыться браузер сервиса, не список мок-профилей.
4. Если id пустые — ошибка «Не задан client id». Это нормально, пока шаг 3 не сделан.

Почта и телефон работают как раньше.

---

## Если не пускает

- **redirect_uri не совпадает** — в кабинете и в `.env` буква в букву `pvzpro://oauth`.
- **Сборка старая** — после правки `.env` нужен новый OTA.
- Сборка **pzbro** — схема `pzbrodev://oauth`. Её же укажи в кабинетах и в `.env`.
